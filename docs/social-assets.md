# 社群素材：30 秒教學影片、規則圖卡（繁中、英、韓）

大腦筋 11/3 寫。Zach 11/3 說「派」。推廣計畫在 `sites-data/research/marketing-community.md`（第 6 節時間表）。

## 為什麼

- 第 3 季 11/10 開播，Zach 要在 Threads、Reddit r/TheDevilsPlan、PTT 韓綜板、Naver 部落格發文。
- 發文要有東西可以貼：一段看了就懂怎麼玩的短影片，和幾張規則圖。文字連結自己推不太動。
- 社群上的連結 Google 不算分，但貼文帶來的人會實際來玩，有人轉、有人寫進整理文才會變成真的外部連結。

## 要做的（11/6 前做好）

### 1. 30 秒教學影片（Wall Go）

- 直式 9:16、1080×1920、MP4（H.264），30 秒內。Threads、YouTube Shorts、IG Reels 共用。
- 內容：真的在本站下一盤的畫面，節奏快：
  1. 開頭 2 秒一句話講這是什麼：「魔鬼的計謀的牆壁圍棋，現在線上就能玩」。
  2. 中間：移動 → 放牆 → 圍出一塊地 → 計分，各一兩步就好。
  3. 結尾 3 秒：網址 quoridorgame.com、「免費、免登入、可以跟朋友連線」。
- 字幕燒在畫面上，三個版本：繁中、英、韓。不用配音，可以有本站自己的音效。
- 用無頭瀏覽器錄（腳本化下一盤），之後新遊戲能照同樣方式再錄。

### 2. 規則圖卡（Wall Go，必要；虎棋可選）

- 4:5、1080×1350，PNG。一組 4～5 張，Threads、IG 輪播都能用：
  1. 這是什麼遊戲（一句話＋棋盤圖）。
  2. 每回合做什麼（移動＋放牆）。
  3. 怎麼結束、怎麼算分。
  4. 一個常見的技巧或陷阱（從我們的規則頁挑）。
  5. 去哪玩（網址＋「非官方粉絲作品」）。
- 三個語系：繁中、英、韓。圖用本站自己的棋盤繪製，跟分享圖同一套風格。
- 這組圖也可以放進 `/wall-go/rules/` 當規則頁的圖（對 Google 圖片也有幫助），放不放你們判斷。

### 3. 每個渠道的連結

- 給 Zach 一張表：每個渠道一條帶 UTM 的網址，例如 `?utm_source=threads&utm_medium=social&utm_campaign=s3`、reddit、ptt、naver。這樣 GA 看得出每篇貼文帶來多少人。
- 確認 UTM 在轉址（例如舊路徑 301 到 `/wall-go/`）後還在。

## 放哪裡

- 成品放 repo 的 `marketing/s3/`（或你們覺得合適的地方），**不要放進網站的 public**（圖卡要放規則頁的那份除外）。
- 做完在【完成】裡列出檔名，大腦筋轉給 Zach，由 Zach 自己發文。**不要替 Zach 發文。**

## 規則

- 不放 Netflix logo、節目截圖、海報、演出者照片，不寫「官方」。
- 每份素材都看得到「非官方粉絲作品」（影片結尾、圖卡最後一張）。
- 不影響網站的部分不用打版。放進規則頁的圖要開分支、跑檢查、**打版前先問 Zach**，這份 docs 一起 commit。
