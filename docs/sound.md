# 音效的出處

牆壁圍棋與虎羊棋對局裡的所有聲音都是**瀏覽器當場用 Web Audio 合成的**（`app/utils/sound.ts`），
專案裡沒有任何音檔，也沒有用到第三方的音效庫或取樣。

| 聲音 | 怎麼做的 |
|---|---|
| 輪到你了 | 兩個正弦波（E5 → A5）加一點高八度泛音 |
| 輪到你超過 1 分鐘沒動 | 同上，音量一半、不帶泛音 |
| 擺棋子 | 濾過的白雜音（「篤」）＋ 190 Hz 正弦波 |
| 蓋牆 | 兩段不同頻帶的濾波雜音 ＋ 140 Hz 三角波 |
| 催一下 | 敲兩下：低頻帶濾波雜音 ＋ 95 Hz 正弦波 |
| 開局、分出勝負 | 三角波的短琶音（勝：C E G C 上行；負：A → E 下行） |

其他遊戲各有自己的一套（2026-10-24 Zach：每一款都要補上音效、各自設計），合成的內容寫在那款自己的資料夾，
透過 `playSynth()` 拿到同一組零件（正弦／三角波 `tone`、濾波雜音 `noise`、`knock`）。開關跟 Wall Go 共用同一個。

**尼泊爾虎棋**（`components/bagh-chal/sounds.ts`）：塔布拉手鼓 —— 羊是高的「答」、老虎是低的「咚」（音往上揚）。
第一版是銅鈴、手鼓、低吼，Zach 不喜歡；之後先用試聽表的 A 木魚，10/24 Zach 從試聽表 A–F 選了 E。

| 聲音 | 怎麼做的 |
|---|---|
| 羊放上盤 | 一聲高鼓：正弦波 520 → 500 Hz＋高通雜音的「啪」，再疊一點 1040 Hz |
| 羊走一步 | 更輕的高鼓，620 → 600 Hz |
| 老虎走一步 | 低鼓，85 → 125 Hz 往上揚 |
| 老虎吃羊 | 老虎的低鼓（80 → 130 Hz）＋晚 60ms 一聲羊的高鼓＋400 Hz 帶通雜音的悶響 |
| 換你了（連線） | 兩聲高鼓（520 → 600 Hz） |
| 贏／輸 | 四下往上的高鼓收在一聲低鼓／兩聲往下沉的低鼓（110 → 70 Hz） |

- 授權：程式碼本身就是這些聲音，跟網站其他程式碼同一個授權。
- **沒有背景音樂**（2026-10-23 拔掉）：合成的那段被嫌難聽，找過 Pixabay 的日系鋼琴與輕快益智曲也都不合，Zach 決定「留下棋的聲音就好」。
- **節目《魔鬼的計謀》的配樂與音效一律不能用**（Google 發佈商政策禁止侵權內容，處分是整個 AdSense 帳號；大腦 2026-10-23）。
  之後若要換成錄音或音效庫，每個檔案的來源與授權都要補進這份文件。
