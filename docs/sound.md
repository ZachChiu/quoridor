# 音效的出處

牆壁圍棋與虎羊棋對局裡的所有聲音都是**瀏覽器當場用 Web Audio 合成的**（`app/utils/sound.ts`），
專案裡沒有任何音檔，也沒有用到第三方的音效庫或取樣。

| 聲音 | 怎麼做的 |
|---|---|
| 輪到你了 | 兩個正弦波（E5 → A5）加一點高八度泛音 |
| 輪到你超過 1 分鐘沒動 | 同上，音量一半、不帶泛音 |
| 擺棋子 | 濾過的白雜音（「篤」）＋ 190 Hz 正弦波 |
| 蓋牆 | 兩段不同頻帶的濾波雜音 ＋ 140 Hz 三角波 |
| 催一下 | 敲兩下：低頻帶濾波雜音 ＋ 95 Hz 正弦波 |
| 開局、分出勝負 | 三角波的短琶音（勝：C E G C 上行；負：A → E 下行） |

虎羊棋另一套（2026-10-24 Zach：針對虎羊棋找不同的音效），取材自尼泊爾 —— 羊頸上的銅鈴、madal 手鼓、頌缽：

| 聲音 | 怎麼做的 |
|---|---|
| 羊放上盤 | 短的濾波雜音 ＋ 兩聲「銅鈴」（1320、1480 Hz 的基音加 2.76／5.4／8.93 倍的不和諧泛音） |
| 羊走一步 | 銅鈴一聲 |
| 老虎走一步 | 「手鼓」：音高從 150 掉到 92 Hz 的正弦波 ＋ 一點拍皮的高頻雜音 |
| 老虎吃羊 | 重的手鼓（125 → 58 Hz）＋ 悶響 ＋「低吼」（420 Hz 低通雜音，音量以 28 Hz 抖動） |
| 換你了（連線） | 兩聲高的銅鈴（B5、E6） |
| 贏／輸 | 「頌缽」：同一套泛音、拉長衰減，兩聲往上（G4 → C5）／往下（D4 → A3） |
