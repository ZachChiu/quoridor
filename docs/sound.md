# 音效的出處

牆壁圍棋對局裡的所有聲音都是**瀏覽器當場用 Web Audio 合成的**（`app/utils/sound.ts`），
專案裡沒有任何音檔，也沒有用到第三方的音效庫或取樣。

| 聲音 | 怎麼做的 |
|---|---|
| 輪到你了 | 兩個正弦波（E5 → A5）加一點高八度泛音 |
| 輪到你超過 1 分鐘沒動 | 同上，音量一半、不帶泛音 |
| 擺棋子 | 濾過的白雜音（「篤」）＋ 190 Hz 正弦波 |
| 蓋牆 | 兩段不同頻帶的濾波雜音 ＋ 140 Hz 三角波 |
| 催一下 | 敲兩下：低頻帶濾波雜音 ＋ 95 Hz 正弦波 |
| 開局、分出勝負 | 三角波的短琶音（勝：C E G C 上行；負：A → E 下行） |

- 授權：程式碼本身就是這些聲音，跟網站其他程式碼同一個授權。
- **沒有背景音樂**（2026-10-23 拔掉）：合成的那段被嫌難聽，找過 Pixabay 的日系鋼琴與輕快益智曲也都不合，Zach 決定「留下棋的聲音就好」。
- **節目《魔鬼的計謀》的配樂與音效一律不能用**（Google 發佈商政策禁止侵權內容，處分是整個 AdSense 帳號；大腦 2026-10-23）。
  之後若要換成錄音或音效庫，每個檔案的來源與授權都要補進這份文件。
