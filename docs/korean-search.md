## 2. 判讀

- **時間點跟第 3 季對得上**：9/26 開始有量，「데블스플랜3」的搜尋也冒出來了。第 3 季 11/10 上線，播出前後韓國的量會再往上。
- **主要問題是排名，不是標題**：
  - 벽바둑 平均排第 7 名左右，這個位置的點擊率本來就只有幾 %。65 次曝光大約該有 1～2 次點擊，拿到 0 次還不能斷定是標題的問題。
  - 要進到前三名，點擊才會明顯增加。
- **`/ko/` 跟 `/ko/rules/` 在搶同一個詞**：兩頁都被 Google 拿去配「벽바둑」。規則頁的標題是「게임 규칙 | 벽바둑 Wall Go」，跟首頁的分工不夠清楚。
- **韓國主要用 Naver**，Google 看到的只是一部分。網站目前沒有登錄 Naver（頁面上沒有 `naver-site-verification`），Naver 那邊可能根本沒收錄。
- 已確認沒問題的：
  - 網址結尾少斜線時都會 301 轉到有斜線的網址（`/ko/rules` → `/ko/rules/`）。
  - sitemap 裡有 `/ko/`、`/ko/rules/`、`/ko/solo/`，robots.txt 全部允許。

## 3. 要改什麼

這份是 `growth-plan.md`「3. 要做的事 → 現在」第 1、3 項的韓文部分。數據顯示韓國最先動起來，所以先做韓文。

1. **首頁標題改用第 3 季也會被搜到的節目名**
   - 現在的標題是 `벽바둑 Wall Go 무료 온라인 | 데블스 플랜: 데스룸`，用的是第 2 季的名字。
   - 韓國人搜的是 `데블스플랜`、`데블스플랜3`，常常不加空格。標題改用通稱，例如 `벽바둑 Wall Go 무료 온라인 | 넷플릭스 데블스 플랜`。
   - 說明（description）保留「在第 2 季《데스룸》出現的遊戲」，再補一句第 3 季。**第 3 季的韓文正式名稱要先查證**，不要自己翻。
   - 用詞先改進 `app/i18n/glossary.md`。
2. **規則頁的標題改成接「規則、玩法」這類詞，跟首頁分工**
   - 現在的規則頁標題是 `게임 규칙 | 벽바둑 Wall Go`。
   - 改成以「벽바둑 규칙」「벽바둑 하는 법」開頭。`titleTemplate` 會再接一次站名，注意不要重複。
   - 分工：首頁接「벽바둑」「벽바둑 온라인」，規則頁接「벽바둑 규칙」。
3. **規則頁加上李世石（이세돌）在節目裡對局的段落**，韓文先做
   - 「이세돌 벽바둑」是韓國特有的搜法，李世石在韓國的知名度最高。
   - 內容要照節目查證，不要編。
4. **加上 Naver 的驗證標籤**：等站長在 Naver 拿到驗證碼再加，可以用 Next metadata 的 `verification.other`。
5. **檢查**：
   - 動到 `metaTitle`、`showName` 這類標題文案，要跑 `npm run og:build`（CI 有 `og:check` 擋著）。
   - 韓文用系統字型，不用跑 `font:subset`。
   - 照常跑 `lint`、`typecheck`、`test`、`build`。

## 4. 站長要做的

- 到 Naver Search Advisor（searchadvisor.naver.com）登錄 `quoridorgame.com`，選 HTML 標籤驗證，把驗證碼交給 quoridor 的對話。
- 驗證通過後，提交 `https://quoridorgame.com/sitemap.xml`。

## 5. 怎麼驗證

上線 2～4 週後，由資料中心查 Search Console（只看韓國）：

- 벽바둑 → `/ko/` 的平均排名從 6.8 進到前 3 名。
- `/ko/rules/` 改接「벽바둑 규칙」這類詞，不再跟首頁搶「벽바둑」。
- 韓國每週的點擊從 1～2 次往上增加。

Naver 那邊由站長在 Search Advisor 看收錄的頁數與曝光。

11/10 第 3 季上線後，量會自然變大，所以比較時要看排名與點擊率，不能只看曝光。
