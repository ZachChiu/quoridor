- 第 3 季《The Devil's Plan: Dead Again》**11/10（二）**在 Netflix 上線（官方已公告；詳見 `sites-data/research/marketing-community.md` 第 6 節）。
- 已經有人在搜了。Search Console 10/27～11/2：

- 「devil's plan games list」前幾名是 Reddit、PDF、Medium，沒有專門的整理頁，我們有機會（`sites-data/research/global-opportunities.md`）。

## 開播前（11/6 前上線）

六個語系的 `/season/3/` 都補上這些。用自己的話寫，不抄 Netflix 或新聞稿：

1. **一段介紹**：第 3 季叫什麼、哪天上、在哪看（Netflix）。
   - 集數、是不是分週上架，**有官方來源才寫**。查不到就寫「Netflix 還沒公布」，不要用 Reddit 的轉述。
2. **「先玩前兩季的遊戲」**：列出第 1、2 季已經能在本站玩的遊戲（Wall Go、尼泊爾虎棋、騎士巡遊、九子棋、盲五子棋…以 catalog 為準），每款一句話加連結。讓等開播的人先玩起來。
3. **「開播後怎麼更新」**：寫清楚本頁會在每批上架後整理這季的遊戲，做好能玩的會放上來。
4. **常見問題 3～4 題**（也輸出成 FAQPage 結構化資料）：
   - 第 3 季什麼時候上線？
   - 第 3 季有哪些遊戲？（開播前回答：還沒播，播了會更新）
   - 在哪裡可以玩節目裡的遊戲？
   - 本站跟 Netflix 有關係嗎？（非官方粉絲作品）
5. **title、description**：現在的寫法可以，但 description 不要只寫「敬請期待」，改成講這頁能做什麼（例如「開播前先玩前兩季的遊戲，開播後每週整理第 3 季的遊戲和規則」）。各語系照當地人搜的叫法（日文「悪魔の計略」、韓文「데블스 플랜」、英文「The Devil's Plan」、繁中「魔鬼的計謀」、簡中「恶魔的计谋」）。
6. 季目錄 `/season/` 和平台首頁連到第 3 季頁的地方，加一行「11/10 上線」之類的提示，讓人找得到。

## 開播後（11/10 起，每批上架後 1～2 天內）

- 每款遊戲一小段：名稱（各語系怎麼叫）、目標、主要規則，**用自己的話寫、不放節目截圖、不放 Netflix 的圖**。
- 能做成線上版的，標「之後會做」；做好了改成連到遊戲頁。
- 整理的人可以看完自己寫，也可以參考公開討論，但不要整段翻譯別人的整理文。
- 每次更新改 `dateModified`，頁面上寫「最後更新：11/xx」。
- 每次更新傳【上線】給大腦筋，寫這次加了哪幾款。不用每次都打版問 Zach 的話，先跟 Zach 確認「第 3 季頁的內容更新」能不能用比較快的流程（例如只改文字就能上）。

## 規則

- 只動第 3 季頁、季目錄、首頁的提示。其他頁不動。
- 不放 Netflix logo、海報、節目截圖、演出者照片。
- 每頁底部的「非官方粉絲作品」照舊。
- 開分支、做完跑檢查、**打版前先問 Zach**，這份 docs 一起 commit。
